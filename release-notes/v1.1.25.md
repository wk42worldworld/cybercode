## Desktop Fixes

- Hides the Windows console window when Code Graph starts its background indexer and file watcher during project session creation.

## Platforms And Downloads

- macOS Apple Silicon and Intel: DMG installers and application ZIPs.
- Windows x64: NSIS installer, installer ZIP, and portable ZIP.
- Linux x64: DEB installer, DEB ZIP, and portable AppImage.
- Signed updater archives and update manifests are included.

The release workflow builds all four native targets and validates the packaged assets and ZIP archives before publishing.
