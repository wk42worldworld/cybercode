# CyberCode v1.1.28

## Windows Background Process Fixes

- Prevents command windows from flashing when starting sessions, checking Computer Use's Python environment, querying Git, indexing Code Graph, searching files, or running scheduled tasks.
- Hides background PowerShell screenshot commands, registry probes, and process cleanup commands, including shell cancellation.
- Coalesces overlapping Computer Use status checks caused by focus changes and preparation polling, while refreshing status after installation or pause actions.

This update builds on the v1.1.27 application baseline. Windows-native regression tests verify that Python and PowerShell launched by a GUI sidecar no longer allocate console windows, and that output and exit codes remain available.

## Platforms And Downloads

- macOS Apple Silicon and Intel: DMG installers and application ZIPs.
- Windows x64: NSIS installer, installer ZIP, and portable ZIP.
- Linux x64: DEB installer, DEB ZIP, and portable AppImage.
- Signed updater archives and update manifests are included.

All four packages are built by GitHub Actions and checked for their bundled runtime resources before publication.
